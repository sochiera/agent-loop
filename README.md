# Battle Brothers — independent clean-slate game

A new, independently implemented, turn-based mercenary tactics game for this Linux PC. This repository starts with **no code imported from earlier Battle Brothers prototypes or Forge missions**. Product intent: [`docs/source/brief.md`](docs/source/brief.md).

The game must become a playable native desktop application, not only a rules library or headless demo. Language/technology is the team's choice — no requirement to be Rust. Forge accepts local commits on its dedicated ref; no push or deployment.
